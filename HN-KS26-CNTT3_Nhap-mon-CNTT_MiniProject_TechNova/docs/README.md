
# TechNova Onboarding Kit
## Hướng dẫn sử dụng
```bash
1.  Clone  repository  về  máy  local
git  clone
2.  Truy  cập  vào  thư  mục  dự  án
cd  IT108-K26_NhapMonCNTT_MiniProject_TechNova
3.  Thiết  lập  biến  môi  trường  bảo  mật
cp  security/.env.example  security/.env
```
## Checklist Onboarding
- [ ] Thiết lập Hybrid Workflow
- [ ] Cấu hình phân quyền chia sẻ tài liệu đúng 3 mức
- [ ] Thiết lập đa Profile trên trình duyệt
- [ ] Cài đặt Password Manager (Bitwarden) và bật 2FA/TOTP
- [ ] Cấu hình .gitignore để bảo vệ các tệp chứa Secrets/API Key
- [ ] Hoàn thiện tài liệu SRS và cấu trúc thư mục dự án
## Bảng thiết bị / Tài khoản mẫu

| STT | Tên thiết bị / Dịch vụ | Mục đích sử dụng | Trạng thái / Ghi chú |
| :---: | :---: | :---: | :---: |
