 1. Tạo Profile “Personal” và Profile “TechNova_Work”, mỗi Profile có thư mục User Data Directory độc lập.

 2. Đăng nhập song song 2 tài khoản (VD: 2 tài khoản GitHub) trên 2 cửa sổ Profile khác nhau để kiểm chứng không bị Session Conflict.

 3. Dựng cây Bookmark 3 nhóm: 01_Work_Dev, 02_Onboarding_Docs, 03_Tools; áp dụng mẹo Favicon-only cho các trang quen thuộc.

4. Cài Extension theo 3 nhóm chủ đề: Dev Suite (JSON Viewer, Octotree), Productivity Suite (ColorPicker, Dark Reader), Security Suite (uBlock Origin, Bitwarden).

5. Mở F12 → Elements để Inspect Element và soi CSS Box Model khi giao diện bị lỗi hiển thị.

6. Mở F12 → Network, tích Disable Cache và Hard Reload (Ctrl+Shift+R) để loại trừ nguyên nhân do Cache cũ trước khi kết luận lỗi.

**Lưu ý / Bẫy**

- Không dùng chung 1 Profile cho việc cá nhân và công việc, đặc biệt khi chiếu màn hình trước lớp/khách hàng.

- Không kết luận “website bị lỗi” khi chưa Hard Reload — rất có thể trình duyệt chỉ đang đọc bản Cache cũ.

- Không để Extension ở chế độ Site Access “On all sites” nếu không thật sự cần thiết, để hạn chế rủi ro và tiết kiệm RAM.
